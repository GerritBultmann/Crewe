# Stickeralbum

Statische Vite + React + TypeScript App fuer ein lokales Stickeralbum.

## Funktionen

- Album-Doppelseiten mit Kategorien und Slots
- Sticker anlegen, bearbeiten, loeschen und einkleben
- Drag-and-drop zwischen kompatiblen Slots
- Lokale Speicherung im Browser
- JSON Import und Export
- GitHub Pages Deployment per Actions Workflow

## Lokal starten

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
